标题：彭博社深度专访 Anthropic CEO【中英双语】

这期彭博社专访以 Anthropic 联合创始人兼首席执行官达里奥·阿莫代伊为核心，同时呈现其妹妹、公司联合创始人丹妮拉·阿莫代伊以及 Claude Code 团队等人的观点。报道试图回答一个贯穿全片的问题：一家不断制造更强人工智能、并因此获得巨大商业成功的公司，能否同时兑现“为人类长期利益负责任地开发人工智能”的承诺？Anthropic 的名字来自表示“人类”的希腊词，但它面对的现实并不抽象：模型能力快速增强，公司估值接近万亿美元，产品可能重塑软件业和白领工作，也可能进入情报、国防乃至战争决策。专访因此没有把 Anthropic 简单描述成安全实验室或商业明星，而是把增长、价值观、就业冲击、国家安全和灾难风险放在同一条因果链上考察。

报道首先描绘达里奥身上的反差。他长期公开警告人工智能风险，却也成为这场技术竞赛中最受关注的人物之一。Anthropic 于二〇二一年由一批离开 OpenAI 的成员创立，早期只是处于劣势的研究实验室，如今却成为前沿模型竞争中的突出力量，直接与 OpenAI 等公司交锋。达里奥用“平滑的指数曲线”描述自己的职业体验：很长时间里，外界感觉什么都没发生，但能力积累一旦越过某个阶段，变化会突然显得极其剧烈。报道列举的现实信号包括企业估值飙升、产品高速发布、软件公司市值因新工具出现而大幅波动，以及某些模型表现出突破现代网络安全防线的潜力。早期接触相关能力的公司甚至把它称为“超级武器”，要求 Anthropic 不要发布。这些事实说明，风险讨论并非脱离产品进步的哲学辩论，而是由越来越可用、越来越有行动能力的模型直接推动。

公司内部的领导结构也被呈现为 Anthropic 能够快速行动的重要原因。达里奥更像提出长期方向和宏大判断的愿景型领导者，丹妮拉则负责把这些复杂、不断展开的想法落实为组织行动。兄妹二人从小关系亲密，也一直希望共同完成一件规模很大的事业。这种互补关系使公司既保留对文明级问题的讨论，又能把判断转化为产品、招聘、客户合作和制度选择。达里奥还强调，他每两周会在全公司面前用大约一小时直接谈论自己的想法、行业变化和外部环境，不加修饰地解释正在发生什么。对他而言，这种透明沟通既建立信任，也减轻个人压力；当约三千名员工理解同一套背景和原则时，公司面对外部冲突才可能维持一致立场，而不是在危机到来后临时拼凑说法。

Anthropic 把主要资源押在编程和企业市场上，既是商业选择，也是价值选择。达里奥认为，如果商业模式从根本上与价值观冲突，公司最终只能在背叛原则和失去竞争力之间二选一。他以社交媒体和面向消费者的广告模式为反例：当收入取决于用户停留时长，产品会被激励去追求参与度，甚至制造依赖，由此产生低质量内容和其他社会问题。企业市场的激励则更接近“让模型真正有用”。如果目标是帮助生物技术公司、制药企业和学术团队研究疾病，或帮助能源行业提高效率、降低成本，那么付费客户关心的是任务结果，而非注意力占用。因此，企业业务不仅能带来收入，也让 Anthropic 更容易把“增进生产力和科学能力”的使命同盈利方式对齐。

Claude Code 是这一战略最醒目的成果。报道将其描述为推动 Anthropic 近期增长的重要产品，并提到其发布后，市场对传统软件公司的前景迅速重估，曾有约二千八百五十亿美元市值在一夜之间消失，交易者甚至用带有恐惧意味的绰号形容这次冲击。软件股连续多日承压，表明资本市场已不再把生成式人工智能只当作辅助聊天工具，而是开始考虑它是否会吞噬传统软件的功能和利润。达里奥并不据此断言软件行业整体萎缩。他的判断是，人工智能会把“蛋糕”做大，软件总需求和可实现的功能可能增加；但现有企业在扩大后的市场中占比可能下降，一些公司会贬值，不能及时适应、不能识别关键变化的公司甚至会退出。增长与淘汰可以同时发生，行业扩张并不意味着每个旧参与者都能获益。

Claude 社区和开发者大会中的氛围进一步展示了这种双重性。使用者把 Claude Code 用于写代码之外的多种任务，团队称增长速度一度超过通常的指数趋势。参与者既兴奋于过去无法想象的工作能在极短时间完成，也担心生产率可能出现数量级跃升。当一个人借助模型可以完成过去需要大团队或很长周期才能完成的工作时，工程师是否会成为最早被取代的人群，便成为无法回避的问题。丹妮拉的回答不是“工程师绝对安全”，而是工程工作不等于敲代码。工程师还要理解用户、规划产品、决定下一步方向，并在约束之间作判断。已有技术训练的人在适应新工具上有先发优势，但他们也必须重新定义自己的价值。所谓“人人都成为技术人员”，并不自动保证原来的技术人员保持原位。

就业问题因此从软件行业延伸到整个经济。报道指出，多数美国人担心人工智能导致岗位消失，接近三分之一的人担心自己成为受影响者。达里奥曾提出一个并不乐观的情景：人工智能可能同时带来很高的国内生产总值增速和高失业、高度就业不足、低工资岗位增多及不平等加剧。他还警告，未来五年内，入门级白领岗位可能有相当大一部分被消除，甚至提到一半这一量级。不过，他强调这不是宣扬末日，而是要求社会提前看见问题并作出积极回应。高速增长不会自动转化为广泛共享的繁荣；如果新财富集中在模型、资本和少数高技能组织手中，那么总量指标改善仍可能伴随普通人机会减少。

Anthropic 的研究尝试估计哪些职业最可能在近期大量使用人工智能，管理、金融和法律等领域都可能明显改变。但达里奥承认，没有人能准确列出哪些岗位必然消失、谁会被替代、哪些新岗位一定出现，因为经济系统本身不可预测。他相对乐观的依据，是能力提升会扩张总体产出，从而创造人可以转移过去的新空间；真正困难的是这些空间能否足够快地出现，以及劳动者能否及时获得所需技能。若转移速度慢于岗位消失速度，宏观增长无法阻止社会冲突。采访者追问，大量失业是否会成为革命的条件，达里奥明确说这正是必须避免的结果，而不是可以接受的技术代价。

对于未来人类工作的去向，他提出几个可能方向，但没有把它们包装成确定答案。第一是物理世界，制造、建设和操作现实设备仍需要大量人力。第二是以人为中心、依赖关系和信任的工作，因为至少一部分人仍希望与真人交流。第三是人类对人工智能的方向控制：模型的行动最终要服从某些人的价值和意图，因此人仍需设定目标、选择边界、承担责任。只是这种控制层会很“厚”还是只剩少量决策者，他也无法确定。丹妮拉更强调，人会继续寻找利用人工智能提高生产率的办法，并保留只有人愿意或适合完成的有意义部分。医学是一个类比：社会今天雇用擅长诊断的医生，但当人工智能很快成为更强诊断者时，医生的角色不会原样不动，而会更多转向沟通、判断和照护。这个例子支持的不是“岗位永远不消失”，而是工作内容会重新组合。

专访的后半部分把矛盾推向国家安全。达里奥担忧一个强硬、集权且积极扩张的国家集团，因此认为民主国家必须具备防卫能力。即使他不同意任何一届政府的全部政策，也总体支持把先进人工智能用于合适的国防和情报任务。Anthropic 自二〇二四年起与 Palantir 合作，并在二〇二五年与 OpenAI、xAI 和 Google 一同获得五角大楼价值二亿美元的合同。公司曾把这视为成为政府主要人工智能供应商的机会。报道还提到，Claude 据报被美国军方用于抓捕委内瑞拉总统尼古拉斯·马杜罗的行动。与此同时，Anthropic 否认通过 Palantir 或其他渠道为美国海关与边境保护局工作，也称不相信公司参与了加沙相关用途，并表示会谨慎限定合作范围，只接受自己认可的任务。

真正的冲突出现在使用红线。Anthropic 拒绝允许 Claude 被用于大规模监控和自主武器，因而与五角大楼发生正面分歧，最终遭遇禁用、诉讼和来自总统及国防部长的严厉攻击。外界把公司称为意识形态狂热者或左翼极端分子，达里奥则把事件定义为一场关于政府应如何使用人工智能的公共辩论，而不是私人恩怨。他的理由是，社会尚未充分理解模型何时可靠、何时失灵，也不知道它会强化还是削弱既有价值。在这种未知条件下，商业公司有权限制产品用途，更重要的是尽早建立先例：高能力模型不应因为国家安全名义就获得无限制使用许可。

自主武器红线的核心是最终决定必须由人作出。达里奥并未声称自己知道 Claude 或其他模型在具体军事行动中的全部作用，而是强调，任何涉及生命和武力的决策都不能把责任彻底交给系统。他用“自动判断遭受核打击后便发射核武器的末日装置”说明危险：冲突往往不是因为双方都计划全面战争，而是因为误判、误解和连续升级。缺乏监督的人工智能会加快信息处理和反应，也可能压缩纠错时间，让事故更容易升级。因此，他总体上认为人工智能更可能阻止而非引发美中之间的世界大战，但这个判断附带严格条件；如果没有用途限制和人类监督，结果可能反过来。

人工智能在安全领域也有降低冲突概率的一面。达里奥举情报收集为例：如果一个国家能更完整地了解对手的军事准备，对手可能因为行动更难隐藏而放弃入侵或冒险。这一推理的关键不是让模型自行开火，而是用更好的信息提高威慑和决策质量。由此可以看出 Anthropic 的立场并非拒绝军事用途，而是区分辅助分析、情报与防卫，同自动化杀伤和全面监控之间的性质差异。难点在于，现实部署往往处在灰色地带，一项分析工具也可能成为行动链的一部分。公司愿意进入国防体系，就必须持续说明界线并承受失去合同、政治攻击和市场机会的代价。

这种取舍贯穿 Anthropic 的全部历史。达里奥承认，在理想世界中，公司会在发布第一个聊天机器人前花数年研究所有可能出错的方式；现实中 Anthropic 只把 Claude 的首次发布推迟了几个月。竞争环境意味着过度等待可能让更不谨慎的参与者填补空缺，也意味着任何安全承诺都受到商业生存约束。他主张，公司处于商业领先位置后，反而更有条件把刻度向谨慎方向移动，因为落后者很难承担延迟发布或限制客户的成本。采访中提到的 Mythos 发布被他用作例证：只有具备足够能力和市场地位，企业才更可能主动揭示或限制具有国家安全含义的能力。安全与领先在这里既相互冲突，也相互支撑。

谁应控制这种力量，是比单项产品政策更深的问题。达里奥认真对待政府为何不直接接管顶尖人工智能公司的疑问，但不赞成政府完全接管 Anthropic。他指出，核武器、互联网、全球定位系统和手机等历史上的强大技术，最初往往由政府建造或得到政府主导支持；人工智能却主要在私营部门发展，政府介入较晚。这种结构在他看来危险且不稳定，因为少数公司拥有影响国家和社会的能力，却缺少与能力相称的公共授权。然而，把全部能力交给政府同样令人害怕。答案不是在企业垄断和政府垄断之间简单选择，而是建立基本监管、外部测试和审计机制。

达里奥尤其支持强制性的发布前测试和模型审计。报道将此与美国政策变化联系起来：特朗普重返白宫后撤销拜登时期的人工智能行政命令和相关指导，政府更偏向减少监管，让硅谷自行发展，理由是过度监管可能在产业起飞时扼杀它。但当 Mythos 所代表的能力及国家安全后果难以忽视时，完全放任的合理性也受到挑战。Anthropic 的主张是，不应等到重大事故发生后再争论企业为何没有预见风险。测试制度至少可以在部署前形成共同证据，让政府、公司和独立审计者知道模型具备什么能力、在什么条件下会失效，以及哪些能力需要访问限制。

丹妮拉把这种预防意识与社交媒体的教训相连。社交平台后来面对儿童福祉、心理健康和选举完整性等反弹，如果早期能够看到今天的后果，也许会作出不同选择。人工智能行业“幸运地排在第二”，已经拥有一个可观察的先例，因此没有理由声称无法预见激励扭曲和社会损害。Anthropic 希望在问题发生前主动思考，而不是事后为结果辩护。达里奥也承认，若人工智能真的造成严重事件，公众可能大规模反弹，甚至要求阻止技术发展；如果后果足够严重，这种阻止或许是合理的。维持社会许可不能只靠宣传美好前景，而要靠在利益受损时仍然执行边界。

谈到文明级风险时，达里奥没有给出安全保证。他认为，技术本身、多个国家之间的竞争、同一经济体内多家公司竞逐，以及旧参与者退出后新公司填补空缺，共同构成风险来源。Anthropic 大约一半的工作都在尝试降低风险，但风险不可能归零。他以航空公司作比：一家航空公司可以比同行安全十倍，却无法保证飞机永不坠毁。然而采访者指出，如果每次乘机有四分之一概率坠毁，任何人都不会登机。达里奥同意百分之二十五过高，并说目标正是把概率压到远低于这一水平。这个比喻暴露了人工智能竞赛最尖锐的伦理问题：即使某家公司相对更安全，社会仍要判断绝对风险是否可接受，不能用“竞争者更危险”代替证明自身足够安全。

全片最终没有给出 Anthropic 已解决这些矛盾的结论。达里奥的态度可以概括为“期待最好结果，同时为最坏结果做准备”。他把这项工作视为自己做过的最重要的事；对一些员工而言，它甚至像“最后一份工作”，因为成功的人工智能可能终结大量现有劳动形式。责任感由此既来自创造机会，也来自可能亲手造成伤害。Anthropic 的困境是，如果退出，其他国家和公司仍会继续；如果参与，它就必须承担模型被误用、判断失误和商业妥协的责任。安全公司不能承诺绝无事故，只能证明自己持续降低绝对风险、公开讨论边界，并愿意为原则付出真实成本。

这场专访带来的启示有三层。对企业而言，价值观必须落实在收入模式、发布节奏、客户选择和可执行红线上，而不能只停留在使命宣言；能否拒绝有利可图但不被认可的用途，是衡量原则是否真实的关键。对劳动者和行业而言，人工智能扩大总产出与造成失业并不矛盾，准备工作应同时包括学习使用工具、强化沟通与判断能力，以及建立帮助人们转岗和分享增长收益的制度。对政府和社会而言，既不能把文明级技术完全托付给少数企业自律，也不能因国家安全而取消监督；发布前测试、独立审计、人类最终决策权和明确的用途限制，都是在创新与风险之间建立公共约束的起点。Anthropic 是否真能成为它所宣称的“好的一方”仍未确定，但报道明确表明，评价标准不应只是模型多强、增长多快，而应是它在力量扩大时能否保持透明、接受约束，并对不可逆后果保持足够谨慎。
