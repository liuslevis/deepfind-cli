# 《全球经济逻辑》摘要

本系列共 36 篇。课程建立了一套从世界经济结构推导至大类资产与交易策略的完整框架：

> **全球分工与收入分配 → 债务和杠杆 → 政策与利率 → 跨境资本流动 → 资产定价 → 交易和风险管理。**

## 核心框架

### 分工、债务与财富分化

长期增长来自技术进步和生产率，债务与杠杆只是把未来收入提前释放。财富积累从劳动价值进入债务价值、再进入杠杆价值后，资产增长会显著快于工资，并扩大贫富差距。

当资产价格和债务持续偏离收入，经济会从繁荣进入去杠杆和出清。货币宽松若不能改善收入与生产率，通常只会抬升资产、延后风险并加剧分化。

### 全球化三级分工

课程将全球经济分为消费与资本输出国、生产加工国、原材料输出国。

正反馈阶段中，消费国低利率和加杠杆扩大需求，生产国获得出口、利润与储蓄，资源国获得商品收入，资本追逐高利差和高回报资产。负反馈阶段中，需求下降或利率上升使套息交易逆转，资本回流美元，新兴市场汇率、房地产和股票承压。

全球化的弊端在于收益分配不均。制造业外迁使发达国家的金融资本和高收入群体获利，而传统劳动者收入停滞；生产国在工资、房价和债务上升后，又面临产业外迁与升级压力。这些矛盾最终转化为民粹主义、贸易保护、区域化和存量竞争。

## 政策与周期

债务和杠杆周期不是纯自然过程，而是由货币、财政、监管、产业和行政政策共同决定。研究宏观必须观察管理层如何允许或限制信用进入特定部门。

2008 年以后，全球债务没有真正消失，而是在居民、企业、金融机构、央行和政府之间转移。央行能够缓解流动性问题，却不能单独解决收入不足、生产率下降和结构性债务。

疫情是催化剂而非根源。政策可以让经济脱离流动性危机，却不等于开启新的高增长周期；低增长、高债务、分配失衡和政策空间不足仍然存在。

## 大类资产逻辑

### 债券

美债是全球美元负债成本的核心。短端主要受央行政策影响，长端包含长期增长、通胀和投资回报预期。收益率曲线变平或倒挂，意味着短期融资成本接近或超过长期回报，是投资和风险偏好走弱的信号。

### 汇率

汇率是两个经济体的相对价格，应比较国际收支、产业结构、通胀、增长、利差和政策预期。中观落点通常是利差，OIS 等利率工具可早于央行声明反映政策转折。

汇率行情多为中长周期，适合低杠杆策略。高杠杆和频繁短线会让正确判断也无法兑现。

### 股票

股价由盈利、技术进步和分红形成的长期斜率，与债务、流动性、估值和情绪造成的波动共同组成。

成熟市场更适合指数化和长期配置；发展中市场的投机、换手和杠杆权重更高。美股风险需区分估值泡沫与流动性危机，不能因指数下跌便机械类比历史。

### 商品

商品需求包括实际消费、库存、仓储融资、抵押、套息和投机需求。金融化会改变库存和供需关系，监管及融资成本上升则会使金融库存重新转为现金。

商品交易必须研究成本、产能、库存、现货和期限结构。小众商品更多由仓单、交割和参与者结构决定，不适合直接套用宏观框架。

### 黄金、白银与原油

- 黄金更接近债券和货币信用资产，核心是实际利率、政府债务和信用；
- 白银具有明显工业商品属性，不能按黄金逻辑简单处理；
- 原油连接供给、地缘政治、通胀、利率和资本流动，暴涨与暴跌都可能形成系统性冲击。

## 期限结构与跨资产

现货价格只是结果，期限结构包含库存、融资和未来供需预期。绝对高位与深度 backwardation、绝对低位与深度 contango 都提示追涨杀跌风险。期货 ETF 和波动率产品还必须计算移仓收益或损耗。

跨资产分析不是寻找简单相关性，而是验证共同驱动因素、识别背离与系统性风险。澳元/日元、美债曲线、成长/公用事业比价、油铜比等，都可用来观察需求、利率和风险偏好。

当不同资产信号不同步时，应首先降低仓位并重新检查供给、需求、政策或流动性变量，而不是武断判定某一市场“错了”。

## 方法论

1. 先判断资产是否适合纳入宏观大类框架。
2. 补全“宏观—政策—利率信用—行业市场—交易工具”的传导链。
3. 不把相关性当因果，不用新闻故事直接生成涨跌结论。
4. 优先观察负债成本、杠杆空间和对手盘。
5. 关注预期和边际变化，而不是静态数据。
6. 以能改变行为的经济阈值代替精确点位预测。
7. 采用“假设—验证—修正”的动态决策。
8. 让杠杆、期限和交易频率匹配资金属性。
9. 通过配置、对冲和风险预算代替永久看多或看空。

## 课程脉络

- **1、1.1—7：** 认知、研究方法及大类资产边界；
- **8—12：** 分工、分配、债务、贫富和市场成熟度；
- **13—19：** 全球化三级分工、政策、美债、收益率曲线和波动率；
- **20—24：** 商品金融化、库存和期限结构；
- **25—29：** 原油、页岩油、资源国和油铜比；
- **30—31：** 国际收支、利差与汇率；
- **32—33：** 美股估值、利率及风险防御；
- **34—35：** 资金属性、杠杆、资产配置和职业周期。

## 总结

《全球经济逻辑》的价值，在于把宏大叙事转化为可检验的资产传导链。它不鼓励依靠单一指标预测价格，而是要求理解谁在创造收入、谁在承担债务、政策如何改变资金成本，以及不同资产是否共同验证同一逻辑。
