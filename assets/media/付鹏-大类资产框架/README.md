# 付鹏大类资产框架：内容摘要

本目录收录 4 篇课程，覆盖经济世界观、全球大类资产反馈、跨资产波动率，以及汇率与利率。文件名中包含“FICC”的两篇课程也位于本目录内。

## 一、经济世界观

大类资产框架并不适用于所有可交易品种。能够纳入框架的资产通常需要足够的流动性、市场容量和宏观敏感度；个股、小众商品、农产品等更容易受到公司治理、天气、库存、交割和参与者结构影响。

课程将经济问题概括为三组关系：

1. **分工与分配；**
2. **债务与杠杆；**
3. **收入与贫富。**

长期增长来自技术和生产率，债务与杠杆则放大财富扩张，并使资产价格偏离劳动收入。财富由劳动价值进入债务价值和杠杆价值后，贫富差距会迅速扩大，最终需要通过去杠杆、债务重组、产业升级或收入重新分配回归长期增长路径。

全球化可理解为消费国、生产国和资源国之间的三级分工。正反馈阶段由消费国债务扩张带动生产、贸易、储蓄、房地产和资源需求；负反馈阶段则表现为需求放缓、融资成本上升、资本回流及资产负债表收缩。

## 二、全球大类资产反馈

宏观策略的核心变量不仅是央行，而是管理层整体，包括货币、财政、监管、产业和行政政策。原油因同时影响通胀、利率和政治关系，也是重要外生变量。

美债位于全球资产负债表的核心，因为它决定美元负债成本。由利率和政策可进一步推导：

- 汇率与资本流动；
- 债券与收益率曲线；
- 股票估值与波动率；
- 商品需求及融资库存。

权益市场应区分长期盈利斜率和系统性波动。成熟市场可以通过 ETF 获取长期生产率红利，同时用期权或相关资产防御估值和流动性风险；发展中市场的投机和杠杆占比更高，需要不同的配置和交易方式。

## 三、跨资产与波动率

美元、商品、股票和汇率往往都是利率及资本流动的结果，不能因为价格同步便认定彼此存在直接因果。

波动率可把长期上涨的指数转化为低波动与高波动周期，从而识别系统性风险。跨资产观察的重点不是找到永恒相关性，而是发现不同市场之间的错配：

- 同步时，宏观逻辑得到更多验证；
- 不同步时，可能分别反映供给、需求、政策或流动性；
- 背离本身就是降低仓位、加强防御的提示。

澳元/日元可作为全球需求、套息交易和风险偏好的综合指标。不同资产也可作为同一宏观观点的替代表达，选择应取决于流动性、杠杆、期限和资金属性。

## 四、汇率与利率

汇率分析的基础是国际收支和全球资本流动：

> 经常账户与资本账户 → 经济和通胀 → 货币政策 → 当前及预期利差 → 资本流动 → 汇率。

美元指数只是若干货币的加权结果，不能代替对具体经济体的比较。研究澳元、纽元、加元等货币时，应直接观察各自经济、商品收入和政策预期；研究欧元还需同时观察欧元区内部利差和欧洲对美国的外部利差。

OIS 等高频利率工具能够比央行声明更早反映市场对加息、降息的预期。汇率的大级别转折往往对应货币政策路径的转折。

汇率适合低杠杆、中长周期交易。经济与国际收支数据多按月更新，频繁短线反转与研究周期不匹配。杠杆过高时，即使三至五年的方向判断正确，也会因正常波动和回撤而无法持有。

## 五、统一方法

1. 先判断资产是否真正属于大类资产。
2. 从全球分工、债务和政策出发，推导利率与资本流动。
3. 区分共同原因和表面相关性。
4. 用波动率和跨资产背离识别系统性风险。
5. 观察整条收益率曲线及市场隐含政策预期。
6. 让交易工具、杠杆和持有周期匹配宏观逻辑。
7. 将资金规模、回撤要求和投资目标纳入策略设计。

## 总结

这四篇课程共同搭建了大类资产研究的骨架：以分工、收入、债务和政策解释全球经济，以利率和资产负债表连接各类市场，再通过波动率、跨资产验证和低杠杆执行，把宏观判断转化为可管理的投资策略。
